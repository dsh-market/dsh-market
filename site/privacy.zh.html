隐私说明

最后更新 2026-08-18。本页说明本网站与 dsh-market 插件的数据处理方式。内容依据代码写成，而非依据意图——下面每一条都可以在代码仓库里核对。

一句话版本

插件不会把关于你的任何信息发到任何地方，它只下载你让它下载的东西。本网站会统计访问量，不使用 cookie，也不识别你的身份。

本网站（dshmarket.com）

访问统计

我们使用 Cloudflare Web Analytics。它不使用 cookie，也不做指纹识别或跨站跟踪，记录的是页面访问量和粗粒度的技术信息——来源页、国家/地区、浏览器与设备类型——由 Cloudflare 汇总。我们看到的是数字，不是个人。详见 Cloudflare Web Analytics。

页面会加载什么

一个到 awesome-dsh-plugin.com 的请求，用于显示目录里当前的插件数量，其中不包含关于你的任何信息。没有广告网络，没有社交插件，没有第三方字体，也没有其它脚本。

托管

本站由 GitHub Pages 提供服务。和任何网页服务器一样，GitHub 会为了响应请求而收到你的 IP 地址。详见 GitHub 隐私声明。

Cookie

本站不设置任何 cookie。

dsh-market 插件

插件运行在你自己的 DeepSeek Harness 里，在你自己的机器上。没有 dsh-market 账号，没有我们运营的服务器，也没有任何遥测。我们无法知道你装了什么。

它会连接哪些地方，以及为什么

目标时机发送的内容
awesome-dsh-plugin.com打开市场时一个普通的目录请求，不含任何标识
registry.npmjs.org、github.com安装或检查更新时要获取的包名——与任何一次普通安装发出的请求相同
raw.githubusercontent.com仅在你打开安装弹窗之后该插件截图的请求
api.github.com检查 GitHub 来源插件的更新时被比对的仓库
get.pnpm.io仅当你使用一键安装 pnpm 时一个下载请求

由你发起的请求会去往你指定的地方：WebDAV 备份发往你自己配置的服务器，Gist 同步使用你自己提供的令牌发往 gist.github.com。不配置就不会发生。

只留在你机器上的东西

  • 备份是你 profile 里的文件。它可能包含配置中的密钥——导出或上传前界面会明确提醒你。
  • WebDAV 密码不会存进浏览器。
  • 浏览器存储只保存界面状态——你打开的是哪个标签页、正在恢复的安装、已关闭的提示。不含任何标识，也不记录你装过什么。
  • 导出的日志是给你自己看、用于反馈问题的。home 路径与密钥形状已打码，我们不会把它上传到任何地方。

广告

目前没有广告，也没有任何引入广告的安排。若将来有变化，本页会在变化发生之前说明，且改动会体现在本仓库的提交历史中。

联系方式

更正与疑问请提交 issue。如果本页描述与代码不符，那就是一个 bug，我们希望知道。
