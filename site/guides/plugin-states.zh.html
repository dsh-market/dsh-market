使用指南

「已安装，未生效」是什么意思

「已安装」页里，每个插件旁边都有一行简短的状态。多数时候写的是在正常工作。这一页解释其他几种，以及各自该怎么办。

各种状态

已生效

插件已经加载到正在运行的 DSH 里。不用做什么。

已安装，重启后生效

文件已经在 profile 里，但正在运行的 DSH 在它们到来之前就加载完了插件。重启 dsh web 或桌面端即可。不少插件能在运行中直接加载，所以有的安装不用重启，有的要。

已安装，与当前 dsh 不兼容

插件声明了它支持的 DSH 版本范围，而你的版本不在里面。市场在安装前就会检查，并告诉你它读到的范围。可以升级 DSH，或者找支持你版本的插件版本；更新时，市场能推荐最新的兼容版本。

已安装，未生效

包在磁盘上，但没有东西去加载它。常见原因有两个：它是别的插件依赖的依赖库（会显示「依赖库」），或者它只是一个普通依赖，没有声明任何要让 DSH 加载的内容。如果它被你自己配置里的 Agent 预设挂载，会显示「由你的配置加载」，因为预设是每个会话才加载，不在启动时加载。

如果你本来期待它有功能，先确认它是插件而不只是依赖库，再看它在 profile 里是不是被关掉了。

已安装，校验未通过

文件在，但包不完整，或者找不到可加载的入口，常见于安装被中断，或构建步骤没有跑完。从市场重装通常就好了。

启动时没能加载

DSH 试过加载它，但失败了。宿主日志里会写明错误。出现这种情况时，可以先在市场里把它停用，再慢慢查。

已停用

你或别的管理工具把它关掉了。它仍然装着，可以随时再打开。

为什么市场不干脆写「坏了」。这些状态里有好几种是正常的：依赖库本来就没有自己的行为；由预设加载的包明明在工作，启动列表里却看不到它。市场分不清你属于哪一种时，会如实写它知道的，而不是断言出了故障。
