使用指南

桌面端还是 dsh web：你的插件装在哪里

DeepSeek Harness 有两种用法，各自有一份自己的插件列表。多数「装了却找不到」的问题，是看错了地方。

两份互相独立的列表

dsh web 跑在一台机器上，通常在终端里启动，再用浏览器打开。它的插件装在这台机器上的一个 profile 里，默认叫 web。桌面端是一个应用，有它自己的 profile。装在一边的插件，不会出现在另一边。

各自怎么安装

  • dsh web：在页面里用插件市场，或者在运行 dsh 的那台机器上执行 dsh plugin --profile web add <名字>。
  • 桌面端：应用自己安装插件。用设置 → 插件，或者用应用里的市场，它会把活交给应用自带的插件管理器。

如果 dsh web 跑在服务器上

插件要装在那台服务器上，不是装在你打开浏览器的这台电脑上。你看到的市场页面是服务器提供的，它管理的是服务器上的 profile。

为什么两边的表现略有不同

  • 桌面端的插件管理器有自己的规则。比如，有会话正在用某个插件时，它不让移除；它也不能原地更新市场自己，因为那会把正在做更新的代码一起卸掉。
  • dsh web 上，市场自己运行 pnpm，所以被拒绝的步骤可以重试。见发布等待期。

确认装到了哪里

在你预期的那一边打开插件列表。找不到，就去另一边看看；如果你在不止一台机器上跑 dsh web，也要确认你打开的是你以为的那一台。
